Bug Reporting and General Comments

MARS-ts is maintained in its GitHub repository, which contains the source code, releases, and development history of this browser port.

  • To report a bug or request a feature, open an issue on the Issues page. Please include sufficient information to recreate the problem: the steps taken, the expected and actual results, your browser and operating system, and the assembly program if appropriate.
  • For questions, general comments, and ideas, join the conversation on the Discussions page.

As a recommended best practice, search existing issues and discussions first; your intended report may already be under way!

Original MARS

Historical record. The Java MARS release maintained its web page at http://www.cs.missouristate.edu/MARS/ and asked that bug reports and general comments be emailed to Dr. Pete Sanderson at PSanderson@otterbein.edu with “MARS” in the subject line. These contacts are preserved as history; the original authors do not support MARS-ts, so please report problems with this port through GitHub instead.
