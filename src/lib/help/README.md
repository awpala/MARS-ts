# Help articles

This module owns the Help menu catalog and article presentation: the existing F1 overview and About MARS content, plus ten articles adapted from the original MARS help. Help and About MARS remain the first two menu entries, followed by a thin divider separating the added article entries. Venus owns the selected article and opens it using the application’s shared [Modal](../venus/components/dialogs/Modal.svelte). The generic dialog remains outside this module; it owns focus containment, initial focus, dismissal, scrolling, and focus restoration. Help owns no editor, simulator, or browser-storage state. Each embedded code block has a Copy icon and an Open as new file icon. Both controls use the shared [Clipboard component](../venus/components/transfers/Clipboard.svelte), with copy-code and transfer-to-file variants. Copy uses the Clipboard API with inline success/failure feedback; opening delegates the exact displayed code text to Venus’s normal new-file/edit workflow, preserves existing buffers, closes Help, and respects Auto Save. Opening code is disabled during execution. Article attachments mount these Svelte controls beside each intact HTML code block and unmount them on teardown; late clipboard completions cannot update a disposed control.

The catalog keeps menu metadata in the initial bundle and dynamically imports each reviewed HTML fragment only when its article opens. Vite emits these fragments as separate hashed JavaScript assets; the F1 overview and About content remain immediately available. The dialog shows loading status or a load-failure message while preserving dismissal and focus behavior. Closing or switching articles discards the previous view, so a late import cannot replace the current article. The article component renders only these trusted, repository-authored module strings; never pass editor text, imported files, arbitrary network responses, or other user content to its raw-HTML path. Articles use scoped descendant styling for readable headings, lists, code, and tables in both themes. The syscall service reference has a keyboard-focusable scroll region capped at 420 px or 55% of the viewport height, with sticky column headers and alternating row bands in both themes. Its fixed column proportions allocate 20% to Service, 12% to Code, 26% to Arguments, 26% to Result, and 16% to MARS-ts; narrow viewports can scroll horizontally. External reference and license links open a separate tab while the article remains open. There is no runtime dependency on the legacy tree or a remote documentation site.

## Legacy sources and attribution

Adapted from MARS, copyright 2003–2013 Pete Sanderson and Kenneth Vollmar, under the [MIT license](../../../MARSlicense.txt). Each derived fragment retains its own source and copyright header; articles display attribution and a link to the bundled license. Contributor names, original article dates, historical release dates, bibliography dates, and example credits are retained. The original Java files and help pages remain unchanged.

The original [HelpHelpAction.java](../../../_legacy-app/mars/venus/HelpHelpAction.java) organized these documents into Swing tabs. The browser exposes each requested article as a Help dropdown entry with a same-tab dialog. Its generated instruction/directive tables, Instruction Set Song, command-line help, and other unrequested tabs are not part of this content addition. Existing browser overview and About content were moved from Venus into this module; the [About action](../../../_legacy-app/mars/venus/HelpAboutAction.java) is the legacy counterpart of the latter.

## Maintenance and validation

Update current-use articles when their corresponding implemented workflows change. Preserve historical records and explicit legacy examples; do not silently rewrite Java release history into TypeScript history. Keep availability notes consistent with the [syscall registry](../engine/syscalls/README.md), [Venus workflows](../venus/README.md), and [implementation guide](../../../IMPLEMENTATION.md). Consequential behavior adaptations remain governed by [ADR 0002](../../../docs/adrs/0002-port-fidelity.md), [browser files](../../../docs/adrs/0003-browser-file-workflows.md), and [cooperative execution](../../../docs/adrs/0004-cooperative-simulation.md).

The [browser scenarios](../../../tests/browser/help.spec.ts) exercise on-demand article loading, failed and late imports, every menu article, retained attribution and dates, syscall availability, long-article and sticky-table scrolling, exact snippet copying, clipboard failure feedback, new editor sources, keyboard dismissal/focus restoration, and the existing overview access path. The [desktop scenarios](../../../tests/browser/desktop.spec.ts) cover About MARS and its license link, Settings menu ordering and separators, and shared menu/toolbar toggle state before and after reload. App gates validate the component/catalog integration. This content addition changes no engine algorithms and makes no new oracle-parity claim.
