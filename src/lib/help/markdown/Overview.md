# MARS Help

New creates a source file; Open selects saved files in this browser. Save commits your source locally, and Auto Save commits edits automatically when enabled. Open tabs and in-progress text are recovered after reload. Import reads .asm or .s files, or ZIP archives of them, from your computer; Export downloads copies.

Registers remain visible beside Edit and Execute. Use the toolbar toggles to change value display and label visibility.

Assemble (F3) translates the current source. Go (F5), Step (F7), Backstep (F8), Pause (F9), Stop (F11), and Reset (F12) control execution. Select breakpoints in Text Segment below unlimited speed, even while Go is running. File → Dump Memory (Ctrl+D) exports text or data memory; Tools are deferred.

The Help menu also contains Introduction, Debugging, Settings, Syscalls, Exception Handlers, Macros, Tools, Limitations, Release History, Bugs/Comments, and Acknowledgements articles.
