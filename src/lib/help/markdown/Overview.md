# MARS Help

The standalone MARS-ts.html opens directly in a desktop browser, including offline. It carries the application only; saved sources and recovery stay in browser storage. Use Export MARS to download all of that data, or export your sources, before moving, renaming, or replacing the HTML, and Import MARS to bring it back. Read Online and other web links require a connection.

New creates a source file; Open selects saved files in this browser. Save commits your source locally, and Auto Save commits edits automatically when enabled. Open tabs and in-progress text are recovered after reload. Import File(s) reads .asm or .s files, or ZIP archives of them, from your computer; Export File downloads copies. Export MARS downloads all MARS data stored in this browser (saved sources, open files, settings, and the session) as one mars-ts-data.json file; Import MARS replaces this browser's MARS data with such a file after you confirm, then restarts MARS.

Registers are shown beside Edit and Execute by default; use the Register Banks switch in the menu bar to hide or show them. Use the toolbar toggles to change value display and label visibility.

Assemble (F3) translates the current source. Go (F5), Step (F7), Backstep (F8), Pause (F9), Stop (F11), and Reset (F12) control execution. Select breakpoints in Text Segment below unlimited speed, even while Go is running. File → Dump Memory (Ctrl+D) exports text or data memory; Tools are deferred.

The Help menu also contains Introduction, Debugging, Settings, Syscalls, Exception Handlers, Macros, Tools, Limitations, Release History, Bugs/Comments, and Acknowledgements articles.
