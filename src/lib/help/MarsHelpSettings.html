Configuration Settings

Original article: Release 4.5 · August 2014

Settings menu checkboxes control display, input, assembly, and execution. The first four entries are Show Labels Window, Popup dialog for input syscalls (5,6,7,8,12), Addresses displayed in hexadecimal, and Values displayed in hexadecimal. These share their state with the corresponding toolbar buttons; a separator follows Values displayed in hexadecimal. Preferences are stored in this browser’s localStorage when available; if storage is unavailable, changes remain in memory. Java MARS retained settings beginning with Release 3.2 through java.util.prefs.Preferences (the Windows Registry on Windows); the browser does not use that mechanism.

Display and input

  • Show Labels Window: off by default. Shows program labels and addresses beside the Text Segment, with Data/Text filters and sorting.
  • Addresses displayed in hexadecimal: on by default. Turn it off for decimal addresses.
  • Values displayed in hexadecimal: on by default. Turn it off for decimal memory and register values.
  • ASCII data display: off by default. Interprets Data Segment bytes as characters and disables editing in that view. Its state is shared by the toolbar and Data Segment checkbox.
  • Show line numbers: on by default in the source editor. Its toggle is at the end of the editing toolbar group, after the undo/redo and clipboard actions.
  • Popup dialog for input syscalls: off by default; introduced in Java Release 4.0. Services 5, 6, 7, 8, and 12 normally read in Run I/O. Enable this toggle for same-tab input dialogs. This does not enable the separate, unfinished dialog services 50–59.
  • Appearance: the menu-bar sun/moon switch selects light or dark mode; light is the default. The choice persists independently of machine state.

Assembly and execution

The Settings menu has separators after Initialize Program Counter and Self-modifying code. Assembly uses the active source and its explicit .include directives; there is no assemble-all control. A previously saved assemble-all preference is reset when the desktop starts. Included source resolves from current open buffers first, then saved library files.

  1. Assemble file on open: off by default. Automatically assembles a source when opened.
  2. Assembler warnings are considered errors: off by default; introduced in Java Release 3.5. When enabled, any assembly warning makes assembly fail. Unrecognized or ignored directives can produce warnings, as can truncated numeric data.
  3. Initialize Program Counter to global main if defined: off by default; introduced in Java Release 3.8. Uses the address of the text label main declared with .globl main, if present. Otherwise execution starts at the default text address.
  4. Permit extended (pseudo) instructions and formats: on by default. Includes address forms beyond the native 16-bit offset plus register.
  5. Delayed branching: off by default. The instruction after a branch or jump executes before the transfer. Account for the delay slot, often with an explicit nop; the assembler does not automatically add one after every source branch. Introduced in Java Release 3.3. Since Release 3.4, branch offsets are encoded relative to the next instruction regardless of this setting, with simulation adjusted accordingly.
  6. Self-modifying code: off by default; introduced in Java Release 4.4. Permits program writes to user text, execution from user data, and stopped-state editing of text words.

Legacy settings without a current browser control

  • Program arguments (Java Release 3.5, originally off): Java supplied argc in $a0, argv in $a1, and arguments on the stack. Program-argument controls and command-line integration are excluded from this browser application.
  • Editor dialog (Java Release 3.3) and Highlighting dialog (Java Release 3.6): the port uses bundled editor/highlighting presets instead of font and color dialogs. Toolbar display settings and the appearance switch remain available.
  • Exception Handler dialog (Java Release 3.2, automatic inclusion originally off): not yet available. Place the handler in the program or reference its source with an explicit .include directive.
  • Memory Configuration dialog (Java Release 3.7): not yet available. The browser uses the default SPIM-derived layout. The engine also retains CompactDataAtZero and CompactTextAtZero configurations, but no UI selector is exposed.

Source saving has separate controls: File → Auto Save commits edits to the local source library. Recovery backups retain open-buffer text independently of manual Save. Machine state and backstep history are not restored after reload.
