# Source editor views

This group renders source documents and their nested tabs. [EditorPane](EditorPane.svelte) is the Edit view that the desktop's tabbed pane hosts: it composes the tabs above the source editor without a wrapper element and knows nothing about the Execute view or the debugger. The active source filename is bold, including when it is the only open document; inactive filenames retain normal weight. The [workspace state](../../state/README.md) owns buffers, selection, dirty state, file workflows, and undo history; the source tabs and source editor read the nearest desktop through the [desktop context](../../context/README.md) and report edits, selections, scroll offsets, and tab actions to those owners directly, as the dialogs do, instead of receiving each buffer, callback, and preference as a prop. The tabs render the workspace's published tab summaries (identity, name, and unsaved state), the editor renders the current buffer with the run state, line-number preference, and machine instruction metadata, the tabs ask the coordinator whether renaming and reordering are available (not while a program runs or a dialog owns interaction), and the editor withholds instruction hover help while a dialog owns interaction. Dragging a document name before or after another tab changes only open-tab order; Alt+Shift+Left/Right moves the focused tab one position. The workspace preserves selection, dirty buffers, and loaded execution and stores the new order in source recovery. Dragging is unavailable with one tab, during inline renaming, execution, or a blocking desktop workflow. Each SVG Close icon button uses the toolbar’s theme-aware hover background and border colors without changing tab geometry, and shows its filename and the shared Alt+W / Option+W shortcut in a themed tooltip. That shortcut closes the current source from any focused surface through the existing dirty-buffer workflow and modal/run guards; held repeats do not close more sources. Closing or selecting a tab delegates to that owner rather than manipulating a second editor model.

The source view owns its textarea, scroll synchronization, syntax painting, and instruction-hover lifetime. Keyword reference popups retain pointer interaction for scrolling, clicking, and selecting their text; clicking a reference may blur the textarea without dismissing the popup. Leaving the popup, editing, or Escape dismisses it. Highlighting reads the [editor module](../../../editor/README.md), and instruction descriptions read the machine's public instruction metadata. Document tabs reuse the generic strip and native button from [controls](../controls/README.md), retaining their own rename input and focus behavior. The editor registers its textarea with the workspace through an attachment while mounted and clears the handle on removal, which lets the workspace focus and select text for navigation and find/replace; the workspace also stores the scroll offsets the editor reports.

Double-clicking a document name, or pressing F2 on its focused tab button, opens an inline filename input. Enter or moving focus submits through the workspace's existing Save As Rename workflow; Escape cancels without writing. The input owns only its temporary text. Successful commits publish the updated tab label, editor name, dirty state, and recovery record together; invalid names open a warning and retain the latest valid name and source. Closed-library collisions retain replacement confirmation, and failed writes retain the original buffer and library record.

These views present the source editing responsibilities of the legacy Venus editor through native browser editing surfaces. The [Venus guide](../../README.md) records supported behavior and remaining editor limitations. Add source-specific presentation here; keep buffer operations and cross-view state with the workspace.
