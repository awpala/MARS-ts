# Pane layout primitives

This group owns reusable pane structure and resizing interactions. [Pane](Pane.svelte) renders caller-supplied content snippets inside a sized, named section or sidebar. [TabbedPane](TabbedPane.svelte) specializes it by composing tab selection from [controls](../controls/README.md); dividers report geometry changes. Callers own selected tabs, content lifetimes, bounds, and persistence. These components have no desktop context, editor, or machine dependency.

Pane accepts explicit flex, width, height, minimum dimensions, overflow, and column/row/block flow. Explicit geometry overrides the existing `--pane-*` defaults, which let outer desktop layouts supply sizes through CSS custom properties without reaching through scoped component styles. Its default layout is a flex column with zero minimum dimensions and visible overflow; callers choose their own clipping or scrolling. The surface uses theme colors, with `--pane-background` and `--pane-border-color` overrides. It renders one native region without owning headings, selection, persistence, or child resources.

The debugger uses Pane directly for Text Segment, Labels, and Data Segment; Registers and Messages compose it through TabbedPane. Table scrolling and domain headings remain with those debugger views. TabbedPane accepts caller-owned tab labels and selection and passes the selected label to its body snippet; its geometry is supplied through Pane's CSS custom properties. Dividers own pointer capture and keyboard adjustment and release their gesture state. They clamp requested sizes to caller-supplied bounds; the [display preference owner](../../state/README.md) derives those bounds from the desktop geometry and persists committed dimensions.

The controls group's tab strip also accepts an optional control snippet in place of its default selection button. The caller supplies accessible interaction and presentation while the strip retains stable keys and layout. Source tabs use this contract to switch between a filename button and an inline rename input without teaching the generic strip about file workflows.

These are browser composition primitives for the panes and split boundaries of the legacy Venus desktop, following [ADR 0002](../../../../../docs/adrs/0002-port-fidelity.md). Add reusable geometry or snippet-based structure here; source, debugging, and dialog-specific content belongs with its view.
