# Shared interaction feedback

This group owns reusable loading status, hover descriptions, and keyboard-shortcut presentation. Callers supply labels and trigger content. These components do not require desktop context, dispatch commands, or own application preferences.

The loading spinner supplies an accessible status while its parent owns loading state and placement. The shared Tooltip component is the single owner of standard description lifetimes: delayed opening on hover, immediate dismissal when the pointer leaves the trigger (including movement into the tooltip), keyboard-visible focus, viewport placement, explicit dismissal, and cleanup. Standard descriptions do not receive pointer events or extend their own hover lifetime. Ordinary pointer activation dismisses the description; binary toggle controls explicitly keep it open through clicks while their trigger remains hovered, with state-dependent descriptions updated in place. Selection and navigation buttons keep ordinary action behavior. Content scrolling caused by a toggle keeps its description positioned while the trigger remains under the pointer; other scroll dismissal, Escape, window blur, and resize behavior remain in place. Controls declare the click policy through props rather than installing their own tooltip event handlers. Keyboard hints render the caller's shortcut string as theme-aware keycaps while preserving an accessible text alternative.

The source editor's keyword reference documents are the rich-content exception: their token hit-testing, scrollable reference entries, placement, and hover interaction remain owned by the editor view. They do not use the standard short-description Tooltip component.

These browser presentation primitives support the menus, toolbar, debugger, dialogs, and transfer controls described in the [Venus guide](../../README.md). They replace browser-native title hints without moving command policy into feedback. Add reusable status or descriptive interaction here; feature-specific messages and decisions stay with their view or state owner.
