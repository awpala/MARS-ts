# Desktop shell composition

This group composes application-wide menus, toolbar command groups, and repository navigation. It composes generic buttons, selection boxes, and range and binary-switch primitives from [controls](../controls/README.md). Menus and the toolbar consume the shared [command context](../../context/README.md), while reusable dropdowns, buttons, groups, and glyphs accept records, callbacks, or snippets. They do not save sources, assemble programs, or own simulator execution.

Command metadata and shortcut hints come from [presentation utilities](../../utils/README.md); menu and toolbar availability stays synchronized through the same live capability. ToolbarButton specializes the generic Button with toolbar icon geometry and pressed/disabled styling; the generic control supplies native semantics and optional tooltip behavior. Native menu dismissal belongs to the menu bar. SpeedSlider specializes Slider with MARS speed mapping and binds to the desktop's preference owner. ThemeToggle specializes Toggle with sun/moon content and owns its independent browser preference, including pre-paint restoration and storage-failure handling. The GitHub link opens a separate tab. Shared hover descriptions and keycaps come from [feedback](../feedback/README.md).

This composes the menu, toolbar, action, and run-speed presentation formerly coordinated by legacy VenusUI and RunSpeedPanel, with browser appearance and repository controls. The [Venus guide](../../README.md) records the adaptations. Add shell-wide command composition here and domain-free input semantics under controls; put workflow-specific content in its feature group and execution rules in state or the framework-free controller.
