# Desktop shell composition

This group composes application-wide menus, toolbar command groups, footer status, and repository navigation. The Footer renders a parent-resolved current-view filename, optional focused-editor caret position, optional execution status, and breakpoint suspension annotation; it owns no source selection or machine state. It composes generic buttons, selection boxes, and range and binary-switch primitives from [controls](../controls/README.md). Menus and the toolbar consume the shared [command context](../../context/README.md), while reusable dropdowns, buttons, groups, and glyphs accept records, callbacks, or snippets. They do not save sources, assemble programs, or own simulator execution.

Command metadata and shortcut hints come from [presentation utilities](../../utils/README.md); menu and toolbar availability stays synchronized through the same live capability. ToolbarButton specializes the generic Button with toolbar icon geometry and pressed/disabled styling; the generic control supplies native semantics and optional tooltip behavior. Native menu dismissal belongs to the menu bar. SpeedSlider specializes Slider with MARS speed mapping and binds to the desktop's preference owner. The toolbar renders it only in Execute; hiding it in Edit retains the speed value. It presents one evenly spaced stop per distinct speed, with maximum only at the final stop, and stacks granular Plus/Minus buttons immediately to the right. Its view positions map to the existing saved legacy setting domain. ThemeToggle specializes Toggle with sun/moon content and owns its independent browser preference, including pre-paint restoration and storage-failure handling. RegistersToggle supplies the Registers-specific caption, show/hide descriptions, and Toggle’s active/inactive fills, and binds to the desktop’s persisted sidebar visibility immediately before Theme. Theme retains neutral track semantics. The GitHub link opens a separate tab and masks its current-color mark with the external static GitHub SVG. Shared hover descriptions and keycaps come from [feedback](../feedback/README.md).

This composes the menu, toolbar, action, and run-speed presentation formerly coordinated by legacy VenusUI and RunSpeedPanel, with browser appearance and repository controls. The [Venus guide](../../README.md) records the adaptations. Add shell-wide command composition here and domain-free input semantics under controls; put workflow-specific content in its feature group and execution rules in state or the framework-free controller.
