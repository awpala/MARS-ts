# Desktop shell composition

This group composes application-wide menus, toolbar command groups, footer status, and repository navigation. The Footer renders a parent-resolved current-view filename, optional focused-editor caret position, optional execution status, and breakpoint suspension annotation; it owns no source selection or machine state. It composes generic buttons, new-tab links, selection boxes, and range and binary-switch primitives from [controls](../controls/README.md). Menus and the toolbar consume the shared [command context](../../context/README.md), while reusable dropdowns, buttons, groups, and glyphs accept records, callbacks, or snippets. They do not save sources, assemble programs, or own simulator execution.

Command metadata and shortcut hints come from [presentation utilities](../../utils/README.md); menu and toolbar availability stays synchronized through the same live capability. ToolbarButton specializes the generic Button with toolbar icon geometry and pressed/disabled styling; the generic control supplies native semantics and optional tooltip behavior. Native menu dismissal belongs to the menu bar. SpeedSlider specializes Slider with MARS speed mapping and binds to the desktop's preference owner. The toolbar renders it only in Execute; hiding it in Edit retains the speed value. It presents one evenly spaced stop per distinct speed, with maximum only at the final stop, and stacks granular Plus/Minus buttons immediately to the right. The slider and its step buttons fit within the same fixed 29-pixel row height as toolbar actions, so showing the speed controls never enlarges that row. Its view positions map to the existing saved legacy setting domain. ThemeToggle specializes Toggle with sun/moon content, adopts the pre-paint choice on mount, and updates the document theme; it saves its independent browser preference through the [theme preference adapter](../../../browser/README.md), which owns the storage key and storage-failure handling. RegisterBanksToggle supplies the Register Banks caption covering the Registers, Coproc 1, and Coproc 0 tabs, show/hide descriptions, and Toggle’s active/inactive fills, and binds to the desktop’s persisted sidebar visibility immediately before Theme. Theme retains neutral track semantics. The GitHub link composes the generic LinkedResource with its themed tooltip and accessible name, so it opens a separate tab; its current-color mark masks the external static GitHub SVG. MaskIcon is the shared leaf glyph for these static masks: a decorative, `aria-hidden` element that tints a bundled `static/icons` SVG with the current text color at a caller-chosen pixel size. The GitHub link, SpeedSlider's Plus/Minus steps, and the shared CloseButton use it while their controls supply accessible names; like ToolbarIcon, it owns no interaction or state. Shared hover descriptions and keycaps come from [feedback](../feedback/README.md).

This composes the menu, toolbar, action, and run-speed presentation formerly coordinated by legacy VenusUI and RunSpeedPanel, with browser appearance and repository controls. The [Venus guide](../../README.md) records the adaptations. Add shell-wide command composition here and domain-free input semantics under controls; put workflow-specific content in its feature group and execution rules in state or the framework-free controller.
