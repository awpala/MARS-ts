# DOM presentation helpers

This directory owns browser-presentation mechanics that several components share: composing an `aria-describedby` value, centering a row beneath a sticky table heading, and opening native modals with paired focus-restoration cleanup. None has legacy provenance or module-level mutable state.

[describedBy.ts](describedBy.ts) joins the nonempty element IDs of a description reference and returns `undefined` when none apply, so the attribute is omitted instead of rendered empty. The generic [Button](../../components/controls/Button.svelte), [LinkedResource](../../components/controls/LinkedResource.svelte), and [SelectorToggle](../../components/controls/SelectorToggle.svelte) use it to combine a caller-supplied `aria-describedby` with the tooltip's ID, in that order, so every control follows one convention.

[scrollReveal.ts](scrollReveal.ts) scrolls only a given viewport so a target row or cell is centered below the table's sticky heading, and answers whether a target's bottom edge lies within the viewport. Native scroll clamping pins the first and last pages, and horizontal position, other panes, and keyboard focus are untouched. The Text Segment follows the highlighted instruction with it, and the Execute view reveals label destinations, restored selections, and observed writes with it, always scrolling the pane that holds the target instead of the desktop.

[dialogLifecycle.ts](dialogLifecycle.ts) opens a native modal and returns the close-and-restore-focus cleanup used by Modal and TransferStatusDialog. Each invocation captures only that dialog's prior focus target; cleanup restores it only while connected. Modal retains its initial-focus selection and dismissal rules, while the transfer status remains nondismissible. The component attachment owns the returned cleanup, so sharing the mechanics creates no shared dialog owner.

Add a helper here when it is a DOM-level presentation rule used by more than one component. Acquisition helpers return their release callback to the calling attachment; element lifetimes, event listeners, and timers remain owned by their components. Tooltip behavior belongs to the [feedback](../../components/feedback/README.md) group.
