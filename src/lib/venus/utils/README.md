# Venus presentation utilities

This directory owns rules shared by multiple browser views, by desktop state owners, or by a view and the desktop coordinator. Each subdirectory names one stable responsibility and carries its own guide; a helper belongs with the responsibility it serves rather than in a general-purpose bucket.

| Directory               | Responsibility                                                                                                                | Legacy provenance                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [commands](commands/)   | The command catalog, shortcut notation and matching, and the Settings catalog shared by menus, toolbar, keyboard, and toggles | `mars/venus/VenusUI.java` menu structure, shortcuts, and setting descriptions                   |
| [debugger](debugger/)   | Integer table-cell display, Data Segment ranges and paging, and the Labels window's sort states                               | `mars/venus/DataSegmentWindow.java` and `LabelsWindow.java`                                     |
| [dom](dom/)             | Accessible-description ID joining and scroll centering below a sticky table heading                                           | None; browser presentation                                                                      |
| [errors](errors/)       | Conversion of thrown values into displayed failure text                                                                       | None; browser presentation                                                                      |
| [execution](execution/) | Run-speed conversion, the rule for following writes, and the console text and view changes after a settled Go or Step         | `RunSpeedPanel.java`, the register and memory windows, `RunGoAction.java`, `RunStepAction.java` |
| [geometry](geometry/)   | Inclusive clamping and the pane geometry constants that are not persistence limits                                            | None; browser layout                                                                            |
| [sources](sources/)     | The unsaved-change marker, source-commit eligibility, and download filenames for exported sources                             | None; browser file workflows ([ADR 0003](../../../../docs/adrs/0003-browser-file-workflows.md)) |

These helpers carry no mutable session state: they are functions and constant tables, and no module here creates a store, subscription, timer, or Svelte rune. Command metadata describes presentation, while the [desktop context](../context/README.md) connects it to session-owned execution and enablement; adding a hint alone does not implement a command. Utilities may call framework-free engine and browser-adapter APIs for pure computations, such as hexadecimal conversion, simulator-notice classification, and the source-extension rules, and they refer to component types only through type-only imports (the catalog's icon names). They never import component runtime code or the desktop state owners. The only helpers that receive a machine are the Data Segment readers in the [debugger guide](debugger/README.md), and the machine is always an argument rather than retained state.

Several rules are shared on purpose. Integer display delegates hexadecimal conversion to the engine's `Binary` API and preserves unsigned decimal addresses versus signed register and data values, so the register and memory tables agree. Shortcut parsing splits notation such as `Ctrl+S` or `Alt+N / Option+N` into alternative chords, and keycaps, keyboard matching, and the derived `aria-keyshortcuts` values all read that one definition. Clamping lets the lower bound win when the bounds cross, which pane geometry, run-speed steps, and tooltip placement rely on. Source-commit eligibility is a predicate only: Save/Save As enablement, Save All, Auto Save, close prompts, and save validation consult it, while the workspace retains dirty-state tracking, persistence, and error reporting. Displayed failure text uses an `Error`'s message or the string conversion of any other thrown value; translated `ProcessingException` reports and each owner's surrounding wording remain with that owner.

Add a helper when two or more callers repeat the same logic, including general-purpose logic such as clamping or notation parsing, and place it in the subdirectory whose responsibility it extends; add a new subdirectory only for a responsibility none of these names, with its own guide. Skip extraction when similar-looking copies encode different rules. Persisted constants that validate stored records, such as the run-speed maximum, register-width minimum, and the selectable view, tab, and memory-range names, belong to the [browser adapters](../../browser/README.md) and are imported from there. Browser storage itself belongs in those adapters, buffers and history in the [editor](../../editor/README.md), and machine algorithms in the [engine](../../engine/README.md). Floating-point parsing, memory access, register writes, and edit errors remain with their existing engine APIs and view owners. A utility is not an alternate location for a controller, Svelte state singleton, or UI-owned machine model. Unit tests sit beside the helpers they cover. The [Venus guide](../README.md) retains the legacy mapping and behavior contracts.
