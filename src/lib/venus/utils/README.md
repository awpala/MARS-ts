# Venus presentation utilities

This directory owns rules shared by multiple browser views, by desktop state owners, or by a view and the desktop coordinator. It currently centralizes command metadata used by menus, toolbars, keyboard shortcuts, and the console's Clear controls; parsing of that displayed shortcut notation, shared by keycaps, keyboard matching, and derived `aria-keyshortcuts` values; the legacy-compatible run-speed conversion used by both its label and machine assignment, plus the distinct-speed UI endpoint; integer-cell display shared by memory and register tables; inclusive range clamping shared by pane geometry, run-speed steps, and hover/tooltip placement; the leading `* ` unsaved-changes marker shared by the window title and source tabs; the source-commit eligibility rule that keeps new empty buffers out of the library while saved sources may be cleared; and the conversion of thrown values into displayed failure text.

These helpers carry no mutable session state. Command metadata describes presentation, while [context](../context/README.md) connects it to session-owned execution and enablement. Integer display delegates hexadecimal conversion to the engine's `Binary` API and preserves unsigned decimal addresses versus signed register/data values; Enter-to-commit for machine values belongs to the debugger's shared cell input. Shortcut parsing splits notation such as `Ctrl+S` or `Alt+N / Option+N` into alternative chords; the ARIA form names Ctrl as Control and Option as Alt and omits repeated chords, so a control's displayed hint and accessible shortcut come from one definition. Clamping lets the lower bound win when the bounds cross. Source-commit eligibility is a predicate only: Save/Save As enablement, Save All, Auto Save, close prompts, and save validation consult it, while the workspace retains dirty-state tracking, persistence, and error reporting. Displayed failure text uses an `Error`'s message or the string conversion of any other thrown value; translated `ProcessingException` reports and each owner's surrounding wording remain with that owner. Floating-point parsing, memory access, register writes, and edit errors remain with their existing engine APIs and view owners.

Add a helper when two or more callers repeat the same logic, including general-purpose logic such as clamping or notation parsing; skip it only when similar-looking copies encode different rules. Browser storage belongs in the [browser adapters](../../browser/README.md), buffers and history in the [editor](../../editor/README.md), and machine algorithms in the [engine](../../engine/README.md). A utility is not an alternate location for a controller, Svelte state singleton, or UI-owned machine model. The [Venus guide](../README.md) retains the legacy mapping and behavior contracts.
