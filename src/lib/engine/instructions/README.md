# Instruction definitions

This module owns the complete instruction registry, basic execution algorithms, instruction metadata, format identities, tokenized example syntax, and pseudo-instruction expansion. It translates `_legacy-app/mars/mips/instructions/Instruction.java`, `BasicInstruction.java`, `BasicInstructionFormat.java`, and `SimulationCode.java`. The instruction set supplies the actual simulation callback and tokenizer; these descriptors never substitute assembler or execution behavior.

`InstructionHost` replaces the Java base class's direct tokenizer construction and console diagnostics with the owning session's tokenizer factory callback and output sink. Each example uses a fresh tokenizer so a configuration error does not poison later examples. Example initialization remains explicit, preserving the canonical instruction-set initialization order. Java package-protected example initialization is public in TypeScript so the instruction-set owner can call it without subclassing. `SimulationCode` is parameterized by the eventual statement type and retains the original simulate-method responsibility.

Opcode masks and matches are signed 32-bit words. Mask parsing uses exact `bigint` values before applying Java's long-to-int conversion, including long overflow rejection. Format objects and the operand-character array are immutable metadata shared by sessions; mutable token lists belong to their instruction definitions.

The [Java descriptor probe](../../../../tests/oracle/instruction-units/InstructionProbe.java) captures every basic instruction definition and a constructor-overload case. Colocated Vitest tests compare masks, names, descriptions, and formats against that capture. The descriptor tests remain independent of the instruction execution tests.

`ExtendedInstruction` translates the original pseudo-instruction template parser and ordered substitution algorithm, including compact alternatives, delayed-branch markers, signed high/low halves, address addends, next-register lookup, and first-only label substitution. Its host supplies live session settings; expansion receives the actual session register banks and program symbol table. Template lists retain Java mutability. Fixed marker offsets, malformed-template behavior, numeric parsing fallback, and Java signed overflow are preserved. The [extended instruction probe](../../../../tests/oracle/extended-instruction-units/README.md) covers all catalog templates and marker boundaries.

`InstructionSet` translates all 155 basic registrations and their simulation callbacks from `_legacy-app/mars/mips/instructions/InstructionSet.java` in their original order, followed by all 388 pseudo definitions. It preserves mask specificity, signed mask ordering, overwrite behavior for duplicate masks/matches, source example tokenization, case-insensitive matching, and delayed branch/return-address handling. The long cohesive registry remains one class so its canonical ordering and callbacks can be reviewed against the Java source. `pseudo-operations.json` encodes the unchanged contents of `_legacy-app/PseudoOps.txt`, including its original attribution; bundling a JSON string makes the resource available without framework-specific raw-file imports or platform filesystem access. A test verifies the decoded resource byte-for-byte against the canonical file.

The session injects real general/coprocessor registers, memory, delayed-branch state, runtime diagnostic services, and syscall lookup through `InstructionSetHost`. Lookup delegates syscall execution to that session's dispatcher; a missing service raises the canonical syscall exception. Syscall implementations and the execution scheduler are separate owners, and this registry does not provide fake services or a replacement simulator. All host state and floating-point conversion scratch space belong to the instance. Register and memory subscriptions remain owned by the hardware and its consumers; instruction definitions allocate no external resources.

Java integer intermediates retain 32-bit wrapping; 64-bit products and HI/LO accumulation use exact `bigint` with signed long wrapping. Floating-point callbacks preserve single-precision rounding, canonical NaN results, raw-bit moves/sign operations, saturating float-to-int casts, original round-to-even logic, even-register validation, and register write order. The original `sqrt.d` validation of the unused third operand is retained because it is observable through the supplied operand array.

The [instruction-set probe](../../../../tests/oracle/instruction-set/README.md) captures 4,960 full machine-state/error results across every basic callback, 1,644 binary-decode results, the complete pseudo catalog, and Unicode mnemonic matching. This demonstrates those direct instruction operations against Java; complete assembled-program execution still requires the assembler, syscall implementations, and simulator integration. It does not claim exhaustive inputs for every opcode.
