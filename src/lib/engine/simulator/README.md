# Simulator state

This boundary owns execution state and sequencing. `DelayedBranch` ports `mars/simulator/DelayedBranch.java`: registering a branch retains its target through the delay slot, and a successful branch in that delay slot extends the delay while retaining the first target. Each simulator session must own a distinct instance. The Java package-visible coordination methods are public methods for the future TypeScript `Simulator` owner; they do not create platform resources or subscriptions.

Branch targets use signed 32-bit `number` values, normalized with `| 0`. The [Java unit probe](../../../../tests/oracle/assembler-units/README.md) covers cleared, registered, triggered, repeated, and nested-branch transitions. `Simulator` coordinates this state with the translated instruction callbacks, exception dispatch, stop requests, breakpoints, and instruction limits in Java's original order.

The translated source retains Pete Sanderson and Kenneth Vollmar's MIT copyright and permission notice. No semantic divergence is intended.

`BackStepper` translates the complete undo algorithm. Its private Java helper responsibilities retain their names in `BackStep` and `BackstepStack`: reusable records, fixed-capacity circular storage, original statement-reference grouping, and delay-slot snapshots. The session must gate hardware recording callbacks with `enabled()`; add methods themselves intentionally record even when disabled, matching Java. Restoration disables recording until the grouped undo finishes. The fatal callback replaces Java's console/exit boundary. The [backstep probe](../../../../tests/oracle/backstep-units/README.md) compares full hardware restoration and history edge cases.

`Exceptions` translates `mars/simulator/Exceptions.java` over injected session-owned `Coprocessor0` and `RegisterFile` instances. It retains the cause-bit mask, keyboard/display pending bits, bad-address write, EPC subtraction with 32-bit wrap, EXL update, and register access order. The [foundation method probe](../../../../tests/oracle/units/README.md) verifies the cause codes, exact register results, and notification sequences; the [simulator probe](../../../../tests/oracle/simulator-units/README.md) adds exception dispatch and handler execution.

`Simulator`, `SimulatorNotice`, and the browser-neutral `SimulatorAction` retain the canonical loop and named Venus callbacks. Each simulation has one owner until its promise settles, including time spent awaiting console input. Stop listeners release pending input; subscriptions return teardown functions. The controller must stop and await execution before resetting or disposing its machine. Bounded host-supplied yields and asynchronous syscall completion replace SwingWorker and blocking reads as described in [ADR 0004](../../../../docs/adrs/0004-cooperative-simulation.md). No timer, DOM object, or process-wide simulator state lives in this module.
