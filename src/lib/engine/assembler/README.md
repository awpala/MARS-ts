# Assembly front end

This boundary owns source-language metadata, source mapping, tokens, and symbol tables. The translated classes retain the names and responsibilities of their counterparts in `_legacy-app/mars/assembler/`: directive identities and completion, numeric data conventions, source and token locations, token lists, and program labels. The front end tokenizes complete source programs, expands includes and `.eqv` definitions, classifies tokens, and expands supplied macro token lists. `ProgramStatement` also retains source representation, operand resolution, and machine encoding/decoding; `Assembler` runs the original multi-file assembly passes on those representations.

`Directives` preserves canonical declaration order and help text as immutable shared metadata. `DataTypes` retains numeric sizes, limits, and directive range checks. `SourceLine` captures the original filename while retaining its caller-owned program reference. `Token` retains both expanded and original source positions with canonical `TokenTypes` identities. `TokenTypes` preserves the original classification precedence and receives real instruction/register lookup services through `TokenClassificationContext`; it does not contain a substitute instruction set. Java floating-literal parse success is represented by the same accepted decimal/hexadecimal grammar and whitespace boundaries. `JavaCharacter` reproduces the consumed JDK character-category operations using a generated JDK 21 BMP table, avoiding differences between Java and browser Unicode versions. `TokenList` preserves Java's shallow-clone behavior: cloned lists own their sequences but share token objects. `SourceLineProgram`, `TokenizerProgram`, `MacroProgram`, and the diagnostic program contract describe only methods consumed by these classes; they do not replace the program implementation.

`MIPSprogram` ports `_legacy-app/mars/MIPSprogram.java`: each instance retains its source, tokenization, symbols, macros, parsed and machine statements, undo history, and stepped-execution flag. Source reads use injected current virtual-file text with Java line-boundary rules. Preparation reads exactly the supplied file list, preserves the lead program identity, and inserts an optional exception handler first. Assembly and asynchronous simulation delegate to their session owners; successful assembly creates fresh undo history, while assembly failure clears it and retains the previous machine list. Nullable getters preserve the original initialization lifecycle. The [program lifecycle oracle](../../../../tests/oracle/program-units/README.md) checks source/list aliasing, file ordering, includes, and failure state retention.

`ProgramStatement` ports `_legacy-app/mars/ProgramStatement.java` into this source/encoding boundary. Its `ProgramStatementHost` supplies real instruction lookup, session register banks, and current number-display preferences; `StatementProgram` supplies local/global symbols and diagnostic source mapping. It preserves the original fixed operand array, mask insertion, branch offset arithmetic, jump-region checks and operand mutation, invalid-word representation, and independent source/basic/machine setters. Its printable element list retains address/value distinctions and uses current settings on each render. The [statement oracle](../../../../tests/oracle/statement-units/README.md) covers every basic descriptor, signed boundaries, all four display-base combinations, malformed operands, and repeated builds. Instruction execution and instruction-set selection remain their owning classes’ responsibilities.

`Tokenizer` ports the original character-scanning loop, instruction-example tokenization, include prepass, character-literal conversion, and recursive `.eqv` processing. Each instance owns its persistent diagnostics and equivalence dictionary. The dictionary is initialized by whole-program `tokenize`, and all public line overloads retain their Java diagnostic routing. `TokenizerSourceHost` injects path operations and synchronous access to already-available source programs; it does not grant the engine access to browser or Node APIs. The host preserves path spelling and returns a fresh source program for an include, throwing `ProcessingException` on read failure. The source program retains the mutable `SourceLine` list while separately snapshotting its plain source strings, which preserves the Java source-map update behavior. Repeated include paths remain errors, and macro expansion remains `Macro`/`MacroPool` responsibility rather than being duplicated inside the tokenizer.

`Macro` and `MacroPool` port `_legacy-app/mars/assembler/Macro.java` and `MacroPool.java`, including percent and SPIM parameters, register-name exclusion, local label suffixing, overloaded definitions, expansion counters, recursion detection, and original-line history. Macros retain the Java first-occurrence textual replacement behavior, including repeated replacement inside a label already suffixed during the same expansion; they do not substitute by token character position. Counters passed to macro substitution use signed 64-bit `bigint`, while the pool expansion counter wraps as a Java `int`. Each program owns its pool and definitions, and register lookups come from its simulator session.

Each `SymbolTable` belongs to a program and receives its session's global table explicitly; the global table receives null. Optional debug output goes through an injected sink. Label lookup is case-sensitive, insertion order is preserved, returned symbol lists share the original symbol objects, and addresses use signed 32-bit `number` values normalized with `| 0`. The legacy `-1` missing-address sentinel still causes a local symbol at `0xffffffff` to fall through to global lookup. `fixSymbolTableAddress` retains the original algorithm: callers must not request the same address as both original and replacement when matching labels exist, because the Java loop does not terminate in that case. Browser file selection and presentation remain outside the engine.

The [assembler unit probe](../../../../tests/oracle/assembler-units/README.md) records exact Java directive metadata, lookup and prefix behavior, source/token mapping, clone semantics, symbol-table operations and diagnostics, macro expansion and lexical classification, addresses, and delayed-branch state transitions. The [tokenizer probe](../../../../tests/oracle/tokenizer-units/README.md) verifies complete-source tokenization, include errors and mappings, lexical boundaries, equivalence substitution, and persistent diagnostics. Numeric data conventions are covered by the [foundation unit probe](../../../../tests/oracle/units/README.md). The [complete assembler oracle](../../../../tests/oracle/assembler-programs/README.md) compares 603 complete assemblies using the real ported engine classes, including every instruction example and focused success/error cases.

Translated source retains Pete Sanderson and Kenneth Vollmar's MIT copyright and permission notice. Java collection bounds failures become TypeScript `RangeError` with the tested legacy messages. No semantic divergence is intended.

`OperandFormat` translates the original operand-count checks, token-category compatibility rules, diagnostics, and ordered overload selection. The live bare-machine setting is injected; candidate token reclassification from operator to identifier remains observable during overload search. Package-visible Java operations are public static TypeScript methods for the assembler caller. The [operand-format probe](../../../../tests/oracle/operand-format-units/README.md) compares the complete category matrix, integer boundaries, actual instruction specifications, and overload-selection mutations.

`Assembler` translates `_legacy-app/mars/assembler/Assembler.java` in full: first-pass source parsing, labels, directives, macro expansion, global transfers and data backpatching; second-pass pseudo expansion; machine-code generation; duplicate-address diagnostics and the original statement comparator. Its private address-space and forward-reference classes remain implementation-owned. `AssemblerHost` supplies actual session memory, global symbols, register/instruction lookup, current settings, file-descriptor reset, and optional debug output. Java integer wrapping, floating-literal parsing, cast saturation, warning policy, mutable parsed lists, and failure-time memory writes are preserved. Source discovery and file access belong to `MIPSprogram` and its host, not the assembler.
