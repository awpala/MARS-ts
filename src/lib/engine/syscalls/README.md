# Runtime services

This module owns the service abstraction, service-number registry, and individual system-call algorithms from `mars/mips/instructions/syscalls/` and `mars/mips/instructions/SyscallLoader.java`. Each syscall remains a separate class with its canonical name, default number, register/memory effects, and diagnostic behavior. A session injects its own general and floating registers, memory, exception updates, and `SystemIO` adapter; no process-wide state or browser UI is retained here.

The implemented core families are console reads and writes (services 1–8, 11–12, and 34–36), heap allocation (9), and normal termination (10 and 17). Floating services require exact Java numeric runtime callbacks from `SystemIO`; there is no JavaScript decimal-printing fallback. GUI `Exit2` ignores the `$a0` exit status, as the original Swing application does. No command-line integration or process exit is ported.

`SyscallLoader` replaces Java classpath reflection with explicit factories that construct fresh session-owned services. It retains duplicate-class filtering, initial duplicate-number detection, case-sensitive override matching, applying every number override before the final collision check, lazy initialization, and last matching service lookup. The default registry contains the implemented core services; absent file, time, random, MIDI, sleep, and dialog services return null so `InstructionSet` raises the canonical unsupported-service exception. Register an additional translated class through this registry when its complete host contract and oracle tests exist. Configuration failures retain their diagnostic text and throw to the owning browser session instead of terminating the application process.

Input syscalls return promises; `SimulationCode` and the `InstructionSet` syscall callback propagate completion so the simulator waits before executing another instruction. Normal exit retains the original `ProcessingException` with no error list. Invalid input and address exceptions retain their original service-specific messages and CP0 updates. Single/double reads store raw floating bits, string reads preserve Java UTF-16-to-byte writes and newline/NUL rules, and integer arithmetic/addresses wrap to signed 32-bit words.

The [core service oracle](../../../../tests/oracle/core-syscalls/README.md) captures all implemented core services across deterministic input, output, allocation, raw-bit, memory, error, and exit cases. Additional focused tests exercise registry overrides, instance isolation, GUI input prompts, and suspension through the actual basic syscall instruction. File/platform-specific families remain explicitly unimplemented rather than receiving placeholder behavior.
