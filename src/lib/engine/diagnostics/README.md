# Diagnostics

This module owns source locations and diagnostic report composition, translating `mars/ErrorMessage.java`, `mars/ErrorList.java`, and `mars/ProcessingException.java`. Assembler and simulator callers create diagnostics; the UI consumes their locations and reports without reconstructing messages. Each list owns its messages and counters. The session injects its error limit; the default is the canonical `Globals.maximumErrorMessages` value from `Config.properties`.

The program and statement interfaces describe only the source-mapping methods diagnostics consume. They preserve include locations and macro history while allowing the corresponding program classes to be translated independently. They are contracts, not substitute program implementations. Line and column numbers use Java-compatible integer values; no machine-word arithmetic occurs here. Runtime macro prefixes use Java's ASCII trim and signed-int range, including its behavior for malformed or overflowing prefixes.

Reports preserve warning-first grouping, insertion order, the terminal error-limit message, and Linux `java.io.File.getPath` separator normalization from the oracle environment. Filenames remain host-supplied strings; the engine does not open files. Null filenames follow the source getter behavior and are invalid when generating a report, as in Java.

The [Java probe](../../../../tests/oracle/diagnostics-units/DiagnosticsProbe.java) generates exact observations consumed by the colocated Vitest test. It covers source mapping, null programs, runtime macro prefixes, grouping, path normalization, the default error limit, runtime PC wrap, address failures, CP0 updates, and normal termination. `ProcessingExceptionHost` supplies the owning register file and exception-register updater, replacing Java static dependencies; the injected host is explicit in runtime constructor overloads. Unrepresented collaborator behavior still needs integration fixtures when the assembler and simulator are connected. MARS copyright and MIT attribution remain in each translated module and the root license.
