# Hardware state

This module owns each session's general registers, HI/LO, program counter, coprocessors, register access notices, and memory configuration metadata, and sparse memory storage. It translates the corresponding classes in `_legacy-app/mars/mips/hardware/` without shared mutable machine state. `RegisterFile`, `Coprocessor0`, and `Coprocessor1` construct their own `Register` instances. `MemoryConfigurations` constructs the three canonical layout tables for each collection; `Memory` owns separate sparse tables for user/kernel data, descending stack, MMIO, and user/kernel instruction references.

Registers store signed 32-bit `number` values and normalize writes with `| 0`. Coprocessor 1 preserves integer bit patterns, uses an instance-local `DataView` to reinterpret floats, and uses signed 64-bit `bigint` for pairs. The even register holds the low word and the odd register holds the high word; pair operations access the high register first, preserving Java notice order. UI-only getters read float and double values without generating simulated access notices.

Java `Observable` becomes synchronous `subscribe`/`addRegistersObserver` calls returning teardown functions. Observers run in reverse registration order over a snapshot, as Java does. Reads notify before returning; writes update before notifying; register resets are silent. The register-file reset still writes the program counter, and coprocessor 1 reset still writes its condition word. The owner must release subscriptions. The explicit `AccessOrigin` callback replaces Java thread identity; access notices retain GUI/MIPS origin queries without importing platform threading APIs.

Injected host callbacks replace `Globals` backstep, start-label, settings, and access-context dependencies. A callback recording a restore must be supplied only when recording is enabled and must return the previous value, matching the Java `BackStepper` contract. `getStartAddress` returns a validated text/kernel-text label address or null. `MemoryConfigurations` calls its `onChange` collaborator after a real identity change; the session owner must clear memory and change/reset `$gp`, `$sp`, and PC in canonical order. `Memory` receives the same configuration collection and applies it through `clear()`; the backstep engine itself remains a separate collaborator.

The [foundation probe](../../../../tests/oracle/units/README.md) covers raw register storage, notification order, numeric aliases, PC wrap, coprocessor defaults and float/NaN bits, condition flags, layout tables, and configuration register reset values. Host backstep callbacks are integration contracts tested locally; end-to-end backstep and exception execution await their Java-class ports.

`Memory` translates `_legacy-app/mars/mips/hardware/Memory.java` directly, retaining 1,024-word blocks, 1,024-block data/stack/text tables, the 16-block MMIO table, configuration limit clamping, byte access and descending-stack correction, heap allocation, statement references, and range-specific observer records. Its constructor replaces the Java singleton. A required `decodeStatement(binary, address)` host service replaces calls to `new ProgramStatement`; there is no alternate decoder in memory. `MemoryStatement` exposes only the stored binary instruction word, allowing the real program model to implement the contract later. Reads/writes normalize signed addresses and values, while 64-bit double bits use `bigint`; `setDouble` canonicalizes NaNs as Java does.

Memory subscriptions return teardown and release their callback references. To preserve the observable Java contract, removal leaves an inactive range record and `countObservers()` still counts it until `deleteObservers()` discards the collection. `clear()` preserves observer registrations and byte order while replacing storage and resetting the heap. A host notification predicate reproduces the Java distinction between headless execution and a GUI without a program. See the [memory method probe](../../../../tests/oracle/memory-units/README.md) for exact oracle coverage and retained legacy edge cases.
