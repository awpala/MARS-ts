# Source editor

This module owns per-IDE source buffers, tab selection, filenames, dirty state, and edit history. Its controller adapts the responsibilities of `_legacy-app/mars/venus/Editor.java`, `EditPane.java`, and `EditTabbedPane.java`; the Svelte view owns browser events and dialog decisions. It does not parse or assemble MIPS source.

Each mounted IDE constructs its own Editor. Changes are explicit controller calls followed by view snapshots; no controller state crosses SSR requests. The browser presenter restores full working buffers and their saved baselines from localStorage after mounting. Virtual filenames are unique in the source library; reopening a name selects its existing tab and preserves its edits. Closing requires the caller to resolve unsaved changes before invoking the controller. Reordering moves existing buffer objects before or after a target without changing selection, dirty baselines, or history; the workspace persists the resulting tab order. Undo history is per tab, and a new edit clears the redo branch. Desktop recovery captures each undo/redo branch with its source identity and current text and restores it only to an exact matching recovered buffer, preserving conflicting drafts. Default filename numbering advances for new files and skips names already open or reserved by the persisted library. Unmodified Tab replaces the selected text with one literal tab, following `jeditsyntax/InputHandler.insert_tab`; Shift+Tab retains focus traversal as in `JEditTextArea`.

The browser host owns the local working filesystem, Import file selection, and Export downloads under [ADR 0003](../../../docs/adrs/0003-browser-file-workflows.md). Only a successful library commit updates the saved-text baseline. Full current source and baseline are backed up synchronously, even with Auto Save off; Export never marks a buffer saved. The [canonical highlighter](highlighting/README.md) paints source behind the native textarea while preserving selection, caret, tabs, and scroll. The desktop hit-tests those painted instruction and directive tokens for hover help, reading syntax examples and descriptions from the session's instruction registry and directive metadata. Comments, strings, and labels do not trigger instruction help; typing, scrolling, and leaving the token dismiss it. Native directory access is intentionally excluded, and the legacy editor preference dialog is deliberately replaced by the bundled [editor preset](editor-preset.json); instruction popup completion and full Java editor parity remain unimplemented. The unit tests cover buffer lifecycle and isolation; they do not establish Java GUI parity.

Bundled sources open as protected reference buffers with a lock in the tab and a read-only banner. Text changes, rename, save, cut, paste, undo/redo recovery, and Find/Replace mutations are blocked; selection, copying, searching, and closing remain available. Copy to new file creates an ordinary independently named editable buffer containing the exact reference text and license. Reference tabs recover from canonical bundled assets rather than saved draft text and are excluded from Auto Save, Save All, and Export All; individual Export remains available. Viewing a reference preserves the loaded machine and never triggers Assemble on Open. Direct Assemble is disabled for a reference; setting-driven rebuilds continue to target the loaded user source. [ADR 0013](../../../docs/adrs/0013-exception-handler-workflow.md) records the workflow.
