# Help browser scenarios

This group owns the rendered Help browser and standalone articles: navigation, content availability, links, loading/failure feedback, focus, scrolling, and source or clipboard transfers. The production Help catalog and components retain article identity and interaction behavior.

Use the shared [browser harness](../harness/README.md) and the [suite guide](../README.md). Add scenarios here when the contract needs rendered article interaction; catalog and HTML/Markdown companion checks stay with the [Help module](../../../src/lib/help/README.md), and pending operations across desktop removal belong under [session](../session/README.md).
