# Source workspace browser scenarios

This group owns browser workflows for source creation, editing, saved-library operations, naming, open-tab order, and import/export. Scenarios observe the production workspace through its dialogs, editor, storage records, and downloaded files; workspace and editor owners retain the actual file and buffer policy.

Use the shared [browser harness](../harness/README.md) for readiness, stable locators, and archive inspection. Add scenarios here when the contract concerns source identity, contents, persistence through a file workflow, or document ordering. Session-wide recovery and teardown belong to [session scenarios](../session/README.md), while machine execution belongs to [execution scenarios](../execution/README.md). The [suite guide](../README.md) owns run commands, selector conventions, and validation limits.
