# Instruction-set execution oracle

`InstructionSetProbe.java` calls every canonical `BasicInstruction` simulation callback with explicit operand arrays and reproducible machine state. It runs outside the immutable legacy tree in the `mars.simulator` package to inspect the package-visible delayed-branch state. The shared [probe runner](../units/run.mjs) compiles against the existing oracle jar, enforces JDK 21/source freshness, isolates Java preferences, and records exact stdout, stderr, status, source hashes, and invocation.

Run `node tests/oracle/instruction-set/run.mjs --update` to capture and `node tests/oracle/instruction-set/run.mjs --check` to verify. `build-legacy` must already have produced a current oracle jar. The capture is oracle data; do not edit golden output by hand.

The 155 basic definitions each execute 32 cases (4,960 total), covering distinct signed boundary operands, HI/LO arithmetic, register/condition moves, delayed and immediate branches/jumps, byte/half/word/unaligned memory operations, invalid addresses, traps, overflow, invalid syscall services, floating raw bits, double halfway values, signed zero, infinities, NaNs, range boundaries, and odd floating-register validation. Every result includes all general registers, HI/LO, PC, floating registers, CP0 exception registers, condition flags, pending branch state, affected memory words, and exact error report. Memory is allocated once and every potentially touched word is reset before each case; this avoids `Memory.clear()`'s explicit Java garbage collection per case without allowing state to leak between cases. Register banks, condition flags, PC, and pending branches are reset each time.

Additional rows record all 388 pseudo definitions/descriptions/template lists/lengths, 1,644 binary decode results (opcode/ignored-field combinations plus seeded arbitrary words), and Java Unicode case-insensitive mnemonic matching. TypeScript tests execute the actual ported registry and callbacks against those rows, compare all basic metadata against the existing descriptor fixture, and verify per-session isolation. These are direct instruction-operation tests, not a substitute for eventual assembled-program simulator parity or real syscall integration.
