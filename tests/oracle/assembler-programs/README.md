# Complete assembler oracle

`AssemblerProgramProbe.java` runs the unchanged Java assembler with its real instruction set, program/source mapping, memory, macros, and symbol tables. The capture contains 603 assemblies: every catalog instruction example, the existing oracle program sources, and focused directive, macro, multi-file, compact-memory, warning, and failure cases. It records successful machine words, basic/display text, source locations, parsed statements, ordered local/global symbols, exact diagnostics, and memory bytes, including state retained when assembly fails.

Cases exercise data continuation and repetition, automatic and explicit alignment, integer truncation warnings, floating-point hexadecimal literals and rounding boundaries, string escapes, forward references, extern/global declarations, duplicate text addresses, all source segments, macros and recursion, `.eqv`, includes, bare-register restrictions, disabled pseudo-instructions, delayed branches, and both compact configurations. The TypeScript suite uses actual `MIPSprogram`, `InstructionSet`, `ProgramStatement`, `Memory`, `MacroPool`, `Tokenizer`, and `SymbolTable` instances; no substitute assembler or instruction decoder is used.

Run `node tests/oracle/assembler-programs/run.mjs --update` after `build-legacy` to regenerate `golden.json`; use `--check` to compare without changes. The shared runner records the exact command, streams, exit status, JDK major, probe hash, source input hashes, and immutable legacy digest. Expected results are generated only by Java. The focused comparison is `tests/assembler-programs.test.ts`.

These fixtures establish assembly behavior without executing resulting instructions. Unbounded source requests such as enormous `.space`/repetition operations and inputs causing the canonical algorithm to hang are excluded.
