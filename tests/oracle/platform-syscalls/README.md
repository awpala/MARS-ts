# Random and dialog syscall oracle

`PlatformSyscallProbe.java` invokes the actual legacy `SyscallLoader` services 40–44 and 50–59 without changing Java source. The shared [probe runner](../units/run.mjs) compiles against the immutable jar, isolates Java Preferences, records source hashes and exact stdout/stderr/status, and verifies the pinned JDK. Run `build-legacy`, then `node tests/oracle/platform-syscalls/run.mjs --update` to regenerate or `--check` to verify. Never edit expected results by hand.

`random.json` runs headlessly. It covers signed seed and stream-ID boundaries, mixed integer/float/double draws, powers of two and rejection-heavy bounds, zero/negative errors, revisiting independent streams, and reseeding an existing stream. The preexisting [seeded whole program](../programs/random.asm) is enabled in the production-engine corpus comparison too. Unseeded startup entropy is tested through an injected host, not compared with nondeterministic Java values.

`dialogs.json` runs actual `JOptionPane` operations under `xvfb-run -a` with headless mode disabled. A Swing timer finds the active pane, captures its message/type, and supplies deterministic input, confirmation options, or window-close results. It never replaces a syscall algorithm. The probe disposes its windows and the runner removes the display/preferences/class-directory resources. Xvfb, xauth, AWT X11 libraries, fontconfig, and DejaVu fonts are required and provisioned with CI; ordinary CLI and existing method probes stay headless.

Dialog cases cover Yes/No/Cancel/close, numeric null/empty/invalid/boundary/Unicode/whitespace/hexadecimal/NaN/infinity/signed-zero inputs, string truncation and tiny/negative/overflowing bounds, UTF-16 low-byte writes, invalid prompt/destination/suffix addresses, partial memory writes, numeric message formatting, byte-to-char messages, and message-type normalization. Every TSV row contains service/case, original argument/FPU words, response, diagnostic outcome, captured message/type, and final general/FPU/CP0 registers plus the affected buffer bytes. The [Vitest comparison](../../../src/lib/engine/syscalls/platform-syscalls.test.ts) runs rows in capture order to preserve stream state.

The captures establish service effects, not Swing pixel/focus parity. The [browser tests](../../browser/syscalls.spec.ts) separately establish same-tab presentation, Cancel versus Stop, initial focus, no echo, and the existing handler-dispatch integration. [ADR 0014](../../../docs/adrs/0014-random-and-dialog-syscalls.md) records browser adaptations and checkpoint/entropy ownership.
