# Program statement oracle

`StatementProbe.java` exercises the unchanged `_legacy-app/mars/ProgramStatement.java` through the headless JDK 21 oracle. Run `node tests/oracle/statement-units/run.mjs` to capture or add `--check` to compare byte-for-byte. The shared [probe runner](../units/README.md) requires the existing fresh legacy build and records source hashes, stdout, stderr, and exit status.

The fixture contains metadata for all 155 canonical basic instruction descriptors, 931 decode cases across six operand bit patterns and five text addresses, 249 source-encoding cases, and five setter/fallback/error cases. Source cases include every canonical example, signed and unsigned immediate boundaries, branch offsets and signed address wraparound, valid and invalid jump regions, repeated builds, named and numeric registers, FPU registers, missing symbols, and operand-mask mismatch. Each state includes all four address/value display combinations, the full operand array, operand bounds, basic and machine representations, diagnostic output, and legacy diagnostic string rendering.

`ProgramStatement.test.ts` reconstructs the exact descriptor masks and example token lists from this fixture. For decode tests, the injected lookup returns the descriptor chosen by Java for that word; this isolates the statement algorithm from the separately owned instruction-set decoder. Simulation callbacks deliberately throw if invoked: these tests claim statement encoding/decoding parity, not execution parity. Source symbol lookup supplies the probe's `label` address. The separate instruction-set oracle establishes instruction selection and execution behavior when implemented.

The port preserves Java quirks rather than correcting them: decoded non-branch immediates remain unsigned, only a third branch operand is sign-extended, jump encoding changes the stored operand into a word address, source rebuilding appends printable elements, and setters do not recompute other representations. Native Java bounds/null exceptions map to JavaScript bounds/null exceptions; malformed diagnostic string rendering is compared by failure outcome rather than runtime-specific exception class.
