# Assembler and delayed-branch unit oracle

This probe calls the checked-in Java `Directives`, `Symbol`, `SourceLine`, `Token`, `TokenList`, `SymbolTable`, `TokenTypes`, `Macro`, `MacroPool`, and `DelayedBranch` implementations without altering them. It belongs to package `mars.simulator` only to access the delayed-branch coordinator's package-visible methods. The fixture records all directive metadata and declaration order, case-insensitive lookup (including Unicode case boundaries), ordered prefix completion, null numeric-kind queries, symbol address boundaries and mutation, source mapping and original token locations, shallow token-list clones and bounds errors, symbol insertion/removal/relocation and global fallback, duplicate-label diagnostics and debug output, token classification against real Java instruction lookup results, Java floating literal grammar and Unicode identifier cases, macro substitution and overload/recursion behavior, and the complete delayed-branch state transitions including a branch in a delay slot.

Regenerate with `node tests/oracle/assembler-units/run.mjs --update`; verify with `node tests/oracle/assembler-units/run.mjs --check`. Both commands rebuild the unmodified Java oracle through the repository helper. `--reuse-build` is available only for coordinated local runs immediately following another successful oracle build, avoiding concurrent deletion of the shared build directory. The probe compiles outside the legacy tree, runs headlessly with fresh Java Preferences roots, and captures exact stdout, stderr, status, Java version, source hashes, and its invocation in `golden.json`. Expected outputs are generated, never hand-edited.

The [foundation comparisons](../../assembler/assembler-units.test.ts) , [structure comparisons](../../assembler/assembler-structures.test.ts), and [lexical/macro comparisons](../../assembler/assembler-macros.test.ts) consume the committed fixture without requiring Java. Session-isolation tests additionally verify the necessary conversion from Java static delayed-branch state to per-session instances. Instruction lookup outcomes are captured from the real Java `InstructionSet`; the lexical test injects those lookup results and uses the actual ported register files. This verifies classification without pretending the full instruction set is already ported. JDK 21 is enforced, while vendor/patch changes are permitted when the outputs and source hashes still match. These checks do not establish whole-program assembler or simulator parity.
