# Extended instruction oracle

`ExtendedInstructionProbe.java` calls the unchanged Java pseudo-instruction descriptors and substitution methods. The capture includes every definition loaded from `PseudoOps.txt`, both normal and compact templates, tokenized examples, constructor overloads, and lengths with delayed branches enabled and disabled. Every catalog template is expanded using normalized example operands; synthetic cases exercise all substitution markers, signed overflow, high/low halves, local/global labels, next-register lookup, malformed templates, and invalid numeric operands.

Run `node tests/oracle/extended-instruction-units/run.mjs --update` after `build-legacy` to regenerate `golden.json`; use `--check` to compare it without changes. The shared method-probe runner records the exact Java command, streams, exit status, JDK major, probe hash, and immutable legacy input digest. Expected output is generated only by Java. The corresponding Vitest suite is `tests/instructions/extended-instructions.test.ts`.

This proves descriptor and expansion behavior, not instruction execution or assembler integration. Inputs that make the canonical recursive substitution loop nonterminate are deliberately excluded.
