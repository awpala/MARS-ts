# Browser assets

This directory owns public assets for the MARS browser host. The application uses every icon here, along with the favicon and license; the Venus [icon components](../src/lib/venus/components/icons/README.md) reference the theme-dependent glyphs, and theme-independent images are passed through unchanged. Assets added here should serve an existing MARS interface responsibility; they must not depend on the legacy resource directory at runtime.

[llms.txt](llms.txt) is original agent-facing guidance, copied unchanged into the static build and served at `/llms.txt`. The root layout advertises it with a `rel="describedby"` link. It welcomes reading and browser interaction, describes the desktop workflow and browser-local persistence, and distinguishes implemented features from deferred work. It is guidance rather than an access-control mechanism and adds no server runtime.

The companion [robots.txt](robots.txt) is served at `/robots.txt` and permits all crawlers to access all paths.

The legacy-derived [icons](icons/) are hand-authored SVG equivalents of the corresponding 22-pixel toolbar and memory-navigation rasters in [images](../_legacy-app/images/). Each keeps the legacy basename without its size suffix, names its source in its header, and includes the original MIT notice. They use vector geometry rather than embedded raster data; their symbols and colors follow the desktop controls, with simplified small details. This is not a claim of pixel-identical conversion. The set covers New, Open, Save, SaveAs, Dump, Undo, Redo, Cut, Copy, Paste, Find, Help, Previous, and Next; other conversions the application does not use or plan to use are not kept. The other legacy illustrations and tools' imagery are not converted.

The remaining toolbar and pane glyphs (Auto Save, Import, Export, Export All, and Close All; Assemble and the debugger controls; the breakpoint actions; the display toggles; and Data Segment restore) are original geometric artwork named after their actions. Each of these files, like the theme-aware Dump, Previous, and Next adaptations, wraps its artwork and stroke defaults in a `<g id="icon">` group whose colors are page theme variables or `currentColor`, with light-theme fallbacks so the file also renders standalone. The Venus ToolbarIcon references that group through SVG `<use>`, because an `<img>` cannot inherit the page's theme or pressed-state colors.

[icons/GitHub.svg](icons/GitHub.svg) contains the existing repository-navigation mark extracted from the shell link; it is separate from the legacy MARS toolbar artwork. The link uses this external SVG as a decorative CSS mask so its fill follows the current theme without inline SVG markup.

[icons/Plus.svg](icons/Plus.svg) and [icons/Minus.svg](icons/Minus.svg) are original geometric glyphs for granular run-speed changes. SpeedSlider masks them with the current text color and supplies accessible names through their buttons. [icons/Sun.svg](icons/Sun.svg) and [icons/Moon.svg](icons/Moon.svg) are the theme toggle's original sun and moon, and [icons/OpenAsNewFile.svg](icons/OpenAsNewFile.svg) is the original glyph of the Help code-snippet action that opens a new source file; they are masked the same way.

[favicon.ico](favicon.ico) is an unchanged copy of [images/mars.ico](../_legacy-app/images/mars.ico), as requested. The original desktop title-bar image is separately credited to NASA/JPL in [VenusUI.java](../_legacy-app/mars/venus/VenusUI.java). Preserve that credit when using the Mars imagery in the application About content. The bundled [MARS license](MARSlicense.txt) accompanies these copied and adapted assets and is served unchanged as a plain-text file. Help → About MARS opens it in a new tab while keeping the IDE session open.

Pass theme-independent SVGs through as external images with an empty `alt` when the containing button supplies its accessible label; an icon alone must not be the only description of an action. Reference theme-aware glyphs by their `#icon` group and current-color marks by CSS mask instead. Render at the legacy 22-pixel toolbar size initially. Keep icon artwork in these files rather than inline in components, and do not introduce inline raster payloads or remote resource references.

[manifest.webmanifest](manifest.webmanifest) makes the application installable ([ADR 0010](../docs/adrs/0010-pwa-offline-support.md)); the root layout links it. Its [icons/mars-192.png](icons/mars-192.png) and [icons/mars-512.png](icons/mars-512.png) are enlargements of the unchanged favicon rendered in Chromium, so they are soft; replace them with higher-resolution artwork when available. The service worker precaches every file in this directory, so keep assets here small.

The [GUI port mapping](../docs/gui-port.md) records the source owners, initial desktop layout, remaining work, and browser adaptations.

Preparation checks parsed the legacy-derived SVGs as XML and confirmed their view boxes and absence of raster image or script elements. Byte comparisons confirmed the favicon and bundled license match their sources. Browser tests exercise the application with these files; rendered appearance is not compared pixel by pixel against the legacy rasters.
